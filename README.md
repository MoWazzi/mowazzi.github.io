# Mo Wazzi — academic website

Source files for the personal academic website published at
<https://mowazzi.com>.

The website is built with [Quarto](https://quarto.org/) and published through
GitHub Pages.

## Preview locally

```sh
quarto preview
```

## Publish

Pushing to the `main` branch runs the publishing workflow. Quarto renders the
site and publishes the generated files from the `gh-pages` branch.
